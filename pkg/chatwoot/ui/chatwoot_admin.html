Conexões

Cada conexão liga um número de WhatsApp a uma inbox do Chatwoot.

Configure o Chatwoot para começar

Informe a URL do seu Chatwoot, um token de API de administrador e o ID da conta. O token precisa ser de administrador — só assim o evolution consegue criar inboxes e recuperar o segredo do webhook.

  • URL do Chatwoot — o mesmo endereço que você abre no navegador.
  • Token de API de administrador — fica no seu perfil do Chatwoot, em Configurações do perfil › Access Token.
  • ID da conta — o número que aparece na URL, em /app/accounts/1.
